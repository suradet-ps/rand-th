# การมีส่วนร่วม

ขอบคุณที่สนใจมีส่วนร่วมกับ Rand!

เรายินดีต้อนรับผู้มีส่วนร่วมทุกคน แต่โปรดคำนึงว่าเรามีทรัพยากรจำกัด
มักมีงานอื่นในโปรเจกต์ที่กำลังดำเนินอยู่ และแม้เพียงการรับ PR ที่สมบูรณ์แล้ว
ก็ต้องใช้เวลาของเรา (การรีวิวและอาจรวมถึงการดูแลต่อเนื่อง)
ดังนั้นเราอาจใช้เวลาพอสมควรกว่าจะตอบกลับคุณ

## การมีส่วนร่วมทุกประเภท

-   **ขอบเขต:** โปรดพิจารณาว่า "ปัญหา" ของคุณอยู่ในขอบเขตเดิมของโปรเจกต์
    หรือเป็นการเพิ่มเติมความสามารถ โปรดทราบว่าสิ่งใดจะถือเป็น *ข้อบกพร่อง*
    อาจขึ้นอยู่กับมุมมองของคุณ เราอาจเลือกที่จะปฏิเสธการมีส่วนร่วม
    เพื่อหลีกเลี่ยงการเพิ่มภาระงานของเรา

    หากคุณต้องการขยายขอบเขตของโปรเจกต์ (เช่น แพลตฟอร์มใหม่
    หรือการทดสอบ CI เพิ่มเติม) โปรดเตรียมพร้อมที่จะดูแลส่วนนั้นอย่างต่อเนื่อง
-   **การแก้ไข:** หากคุณแก้ไขด้วยตัวเองได้ง่าย โปรดพิจารณาส่ง PR
    แทนการเปิด issue ในทางกลับกัน หากมันไม่ง่ายหรือดูอาจขัดกับงานอื่นที่ทำอยู่
    ก็อย่าลังเลที่จะเปิด issue

## พูลรีเควสต์

-   **บันทึกการเปลี่ยนแปลง:** เว้นแต่การเปลี่ยนแปลงของคุณจะเป็นเรื่องเล็กน้อย
    โปรดเพิ่มหมายเหตุในบันทึกการเปลี่ยนแปลง (`CHANGELOG.md`) ของแต่ละเครตที่ได้รับผลกระทบ
    ภายใต้หัวข้อ `[Unreleased]` ที่ด้านบนสุด (เพิ่มหากยังไม่มี)
    โปรดระบุหมายเลข PR ด้วย (ซึ่งหมายความว่าต้องเพิ่มหมายเหตุ *หลัง* เปิด PR แล้ว)
-   **คอมมิต:** หากมีส่วนร่วมด้วยการเปลี่ยนแปลงขนาดใหญ่ โปรดพิจารณาแบ่งเป็นหลายคอมมิต
    หากเป็นไปได้ให้แต่ละคอมมิตอย่างน้อยต้องคอมไพล์ผ่าน
    การ rebase คอมมิตอาจเหมาะสมเมื่อทำการเปลี่ยนแปลงครั้งสำคัญ
-   **เอกสาร:** เรากำหนดให้ทุกไอเท็มสาธารณะต้องมีเอกสารกำกับ
    อาจใส่ตัวอย่างสั้นๆ ไว้ด้วยในจุดที่เหมาะสม
-   **ความสามารถในการบำรุงรักษา:** สิ่งสำคัญสำหรับเราคือโค้ดต้องอ่านและทำความเข้าใจได้ง่าย
    และไม่ยากต่อการตรวจสอบความถูกต้อง
-   **ประสิทธิภาพ:** เรามุ่งสู่ประสิทธิภาพที่ดีเสมอ และบางครั้งก็ทำงานเพิ่มอย่างมากเพื่อให้ได้มา
    อย่างไรก็ตาม เราต้องประนีประนอมเพื่อความสามารถในการบำรุงรักษาด้วย
    และต้องพิจารณาว่าประสิทธิภาพที่เพิ่มขึ้นเล็กน้อยคุ้มกับความซับซ้อนของโค้ดที่เพิ่มขึ้นหรือไม่
    [ใช้การวัดประสิทธิภาพ](contrib-bench.md)
-   **สไตล์:** ทำให้เรียบร้อย *โดยปกติ* จำกัดความยาวไว้ที่ 80 ตัวอักษร
-   **Unsafe:** ใช้เมื่อจำเป็น ไม่ใช้หากมีทางเลือกที่ดีกว่า
    ทำให้โค้ด `unsafe` ตรวจสอบความถูกต้องได้ง่าย
-   **สัญญาอนุญาตและการระบุที่มา:** โปรเจกต์นี้ได้รับอนุญาตแบบเสรีภายใต้ MIT
    และ Apache Public Licence v2 เราถือว่าการมีส่วนร่วมทั้งหมดอยู่ภายใต้สัญญาอนุญาตเหล่านี้
    ลิขสิทธิ์ยังคงเป็นของผู้มีส่วนร่วมแต่ละราย

    แต่เป็นเพียงกลุ่มของผู้มีส่วนร่วมทั้งหมดในโปรเจกต์นี้ สำหรับข้อมูลเพิ่มเติม ดูไฟล์ `COPYRIGHT`
