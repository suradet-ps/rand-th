# กระบวนการสุ่ม

คุณอาจสังเกตเห็นว่าเทรต [`Distribution`] ไม่อนุญาตให้มีการเปลี่ยนแปลงค่าสถานะภายในตัวเองเลย (ไม่มีเมธอดที่รับ `&mut self`) ซึ่งสิ่งนี้เกิดจากความตั้งใจในการออกแบบ: เนื่องจากการแจกแจงความน่าจะเป็นในทางคณิตศาสตร์ถูกนิยามว่าเป็นการจับคู่เชื่อมโยง (mapping) จากเหตุการณ์ไปยังค่าความน่าจะเป็นที่คงที่

ในทางตรงกันข้าม [กระบวนการสโทแคสติก (Stochastic Process)](https://en.wikipedia.org/wiki/Stochastic_process) คือแนวคิดที่ศึกษาเกี่ยวกับกลุ่มของตัวแปร (หรือสถานะของระบบ) ที่มีวิวัฒนาการเปลี่ยนแปลงไปตามเวลาในลักษณะสุ่ม

ไลบรารีนี้ไม่ได้มุ่งหมายที่จะนิยาม API ทั่วไปเพื่อครอบคลุมกระบวนการสุ่มทั้งหมด หรือจัดเตรียมเครื่องมือสำหรับจำลองโมเดลสโทแคสติกโดยตรง แต่ในบทนี้ เราจะมาพูดคุยถึงแง่มุมการประยุกต์ใช้ที่พบบ่อยบางประการ


## การสุ่มแบบไม่ใส่คืน

ขอยกตัวอย่างคลาสสิก: สมมติว่ามีถุงใบหนึ่งบรรจุลูกแก้วสีแดง 10 ลูกและสีเขียว 30 ลูก ความน่าจะเป็นเริ่มต้นที่จะสุ่มหยิบได้ลูกแก้วสีแดงคือ `10/(10 + 30) = ¼ = 0.25` แต่หากลูกแก้วลูกแรกที่หยิบได้ *เป็น* สีแดง และ *ไม่ใส่คืนกลับลงไปในถุง* ความน่าจะเป็นที่การสุ่มหยิบลูกแก้วลูกที่สองจะได้สีแดงจะลดลงเหลือ `9/(9 + 30) = 3/13 ≅ 0.23`

เครต `rand` ไม่ได้มีระบบสำเร็จรูปสำหรับรองรับการสุ่มแบบไม่ใส่คืนทีละขั้นตอน (step-wise) แต่สิ่งที่มีให้คือการรองรับการสุ่มเลือกสมาชิกที่ไม่ซ้ำกันหลายตัวจากลำดับข้อมูลในคราวเดียว ได้แก่:
[`IteratorRandom::choose_multiple`] และ [`SliceRandom::choose_multiple`]

หากคุณต้องการอิมพลีเมนต์การสุ่มแบบไม่ใส่คืนทีละขั้นตอนด้วยตนเอง นี่คือแนวทางที่สามารถนำไปปรับใช้ได้:

-   ใส่สมาชิกทั้งหมดลงใน `Vec` โดยในแต่ละขั้นตอนให้สุ่มเลือกดัชนีแล้วลบสมาชิกนั้นออก ข้อพึงระวังคือ
    หากชุดข้อมูลมีขนาดใหญ่มาก วิธีนี้จะไม่มีประสิทธิภาพ
    เนื่องจากคำสั่ง `Vec::remove` มีความซับซ้อนระดับ `O(n)` อีกทั้งยังต้องเสียต้นทุนในการสร้างสมาชิกทั้งหมดขึ้นมาก่อน
-   ใส่สมาชิกทั้งหมดลงใน `Vec` แล้วทำการสับเปลี่ยนลำดับ (shuffle) จากนั้นในแต่ละขั้นตอนก็เพียงแค่อ่านดึงสมาชิกตัวถัดไปออกมาเรื่อยๆ
-   สร้างเมธอดสุ่มค่าจากการแจกแจงตั้งต้น ควบคู่ไปกับการใช้ `HashSet` ว่างเปล่าเพื่อบันทึกค่าที่
    "ถูกเลือกไปแล้ว" โดยในแต่ละขั้นตอนให้สุ่มค่าขึ้นมา หากค่านั้นมีอยู่ใน `HashSet` แล้ว
    ก็ให้ปฏิเสธค่านั้นแล้วสุ่มใหม่ แต่หากยังไม่มี ให้บันทึกสำเนาลงใน `HashSet` แล้วคืนค่านั้นออกมา
    ทั้งนี้วิธีนี้จะไม่มีประสิทธิภาพเว้นแต่ว่าจำนวนสมาชิกที่ต้องการสุ่มจะมีสัดส่วนน้อยกว่า
    จำนวนสมาชิกทั้งหมดอย่างมาก
-   ศึกษาเพิ่มเติมจากไฟล์ [`src/seq/index.rs`]: ซึ่งมีอัลกอริทึมการสุ่มตัวอย่างหลายรูปแบบที่ใช้อยู่
    ซึ่งอาจนำมาปรับใช้กับงานนี้ได้
