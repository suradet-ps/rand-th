# การวัดประสิทธิภาพ

โครงการของเรามีชุดทดสอบวัดประสิทธิภาพ (benchmarks) จัดเตรียมไว้แล้วมากมาย:

```sh
cargo +nightly bench

# In a few cases, nightly features may use different code paths:
cargo +nightly bench --features=nightly
```

ชุดทดสอบประสิทธิภาพสำหรับการแจกแจงต่างๆ ในปัจจุบันจะแยกไปอยู่ในเครต `rand_distr` ส่วนชุดทดสอบประสิทธิภาพอื่นๆ ทั้งหมด (รวมถึง RNG ทั้งหมดของเรา) จะรวมอยู่ในเครตหลักอย่าง `rand` (ด้วยเหตุนี้จึงมี dev-dependencies อยู่หลายรายการ)

โค้ดจำนวนมากใน Rand มีความอ่อนไหวต่อประสิทธิภาพสูง และส่วนใหญ่มักถูกเรียกใช้งานซ้ำๆ ในลูปวิกฤต (hot loops) ของไลบรารีหรือแอปพลิเคชันต่างๆ ดังนั้นหากคุณทำการแก้ไขโค้ดใน `rand_core`, ในเครต PRNG หรือในโมดูล `rngs` หรือ `distr` (โดยเฉพาะเมื่อเป็น 'การเก็บกวาดโค้ดที่ดูเหมือนชัดเจน') โปรดตรวจสอบให้แน่ใจเสมอว่าผลการทดสอบ benchmark ไม่ด้อยลง

โปรดรายงานผลเปรียบเทียบก่อนและหลังสำหรับ benchmark ที่ได้รับผลกระทบเสมอ และหากคุณกำลังปรับปรุงประสิทธิภาพในส่วนที่ยังไม่เคยมี benchmark มาก่อน โปรดเพิ่ม benchmark ใหม่เข้าไปก่อนเป็นอันดับแรก จากนั้นจึงค่อยเพิ่มโค้ดที่แก้ไขในคอมมิตแยกต่างหาก (เพื่อให้สามารถวัดผลเปรียบเทียบก่อนและหลังได้ง่าย)
