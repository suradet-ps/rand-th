# การวัดประสิทธิภาพ

เรามี benchmark อยู่แล้วหลายตัว:

```sh
cargo +nightly bench

# In a few cases, nightly features may use different code paths:
cargo +nightly bench --features=nightly
```

benchmark ของการแจกแจงตอนนี้อยู่ในเครต `rand_distr` ส่วน benchmark อื่นๆ ทั้งหมด (รวมถึง RNG ทั้งหมดของเรา) อยู่ในเครต `rand` หลัก (จึงมี dev-dependency หลายตัว)

โค้ดจำนวนมากใน Rand มีความอ่อนไหวต่อประสิทธิภาพ ส่วนใหญ่อยู่ในลูปที่ถูกเรียกใช้งานบ่อยครั้งในไลบรารีหรือแอปพลิเคชันบางตัว หากคุณแก้ไขโค้ดใน `rand_core` ในเครต PRNG หรือในโมดูล `rngs` หรือ `distr` (โดยเฉพาะเมื่อเป็น 'การทำความสะอาดที่ดูชัดเจน') โปรดตรวจสอบให้แน่ใจว่า benchmark ไม่ด้อยลง

โปรดรายงานผลก่อนและหลังสำหรับ benchmark ที่ได้รับผลกระทบ หากคุณกำลังปรับปรุงประสิทธิภาพของสิ่งที่ไม่เคยมี benchmark มาก่อน โปรดเพิ่ม benchmark ใหม่ก่อน แล้วค่อยเพิ่มการเปลี่ยนแปลงของคุณในคอมมิตแยกต่างหาก (เพื่อให้วัดผลก่อนและหลังได้ง่าย)
