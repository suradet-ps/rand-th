## การ import รายการต่างๆ (prelude)

วิธีที่สะดวกและง่ายที่สุดในการ import ไอเท็มจาก Rand คือการเรียกใช้โมดูล [`prelude`]
ซึ่งได้รวบรวมฟังก์ชันและเทรตที่สำคัญที่สุดของ Rand ไว้อย่างครบครัน โดยคัดเลือกเฉพาะรายการที่ไม่เสี่ยงต่อการเกิดปัญหาชื่อชนกัน (name conflicts)

โปรดทราบว่า Rand เวอร์ชัน 0.5 มีการปรับโครงสร้างโมดูลและจัดระเบียบเนื้อหาใหม่เป็นอย่างมากเมื่อเทียบกับเวอร์ชันก่อนหน้า แม้ว่าชื่อเดิมจะยังคงใช้งานได้อยู่ในหลายจุด (แต่ถูกซ่อนไว้ในเอกสาร) ทว่าชื่อเก่าเหล่านี้จะทยอยถูกตัดออกในอนาคต ดังนั้นเราจึงขอแนะนำอย่างยิ่งให้ปรับโค้ดของคุณมาใช้ prelude หรือระบุพาธตามโครงสร้างโมดูลใหม่ในการ import
