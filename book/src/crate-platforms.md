# การรองรับแพลตฟอร์ม

ด้วยความร่วมมือและการมีส่วนร่วมอย่างต่อเนื่องจากชุมชนนักพัฒนา ส่งผลให้เครตต่างๆ ในตระกูล Rand สามารถรองรับแพลตฟอร์มได้อย่างครอบคลุมและหลากหลาย

## no_std

เมื่อกำหนด `default-features = false` ทั้ง `rand` และ `rand_distr` จะสามารถ build และทำงานในสภาพแวดล้อมแบบ `no_std` ได้อย่างสมบูรณ์ โปรดดูรายละเอียดเพิ่มเติมที่ [ฟีเจอร์ทั่วไป](crate-features.html#ฟีเจอรทัวไป)

## getrandom

เครต [`getrandom`] มอบ API ระดับต่ำสำหรับดึงข้อมูลจากแหล่งเลขสุ่มเฉพาะของระบบปฏิบัติการและแพลตฟอร์มต่างๆ ซึ่งถือเป็นหัวใจและองค์ประกอบพื้นฐานที่สำคัญของทั้ง `rand` และ `rand_core` ตลอดจนไลบรารีด้านวิทยาการรหัสลับ (cryptography) อีกมากมาย โดยเครตนี้ไม่ได้ออกแบบมาสำหรับการเรียกใช้งานทั่วไปภายนอกไลบรารีระดับระบบ

### WebAssembly

เนื่องจากเป้าหมายการคอมไพล์แบบ `wasm32-unknown-unknown` ไม่ได้ตั้งสมมติฐานล่วงหน้าเกี่ยวกับ JavaScript interface ของสภาพแวดล้อมปลายทาง ดังนั้นเครต `getrandom` จึงจำเป็นต้องมีการกำหนดค่าคอนฟิกเพิ่มเติม โปรดดูรายละเอียดที่ [การรองรับ WebAssembly](https://docs.rs/getrandom/latest/getrandom/#webassembly-support)

ทั้งนี้ เป้าหมายการคอมไพล์อย่าง `wasm32-wasi` และ `wasm32-unknown-emscripten` จะไม่มีข้อจำกัดดังกล่าว

[`getrandom`]: https://docs.rs/getrandom/
