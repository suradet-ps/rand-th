## การ import รายการต่างๆ (prelude)

วิธีที่สะดวกที่สุดในการ import รายการต่างๆ จาก Rand คือใช้ [`prelude`]
ซึ่งรวมส่วนที่สำคัญที่สุดของ Rand แต่เฉพาะส่วนที่ไม่น่าจะทำให้ชื่อชนกัน

โปรดทราบว่า Rand 0.5 มีการเปลี่ยนแปลงโครงสร้างโมดูลและเนื้อหาอย่างมีนัยสำคัญเมื่อเทียบกับเวอร์ชันก่อนหน้า
ชื่อเดิมจะถูกเก็บไว้เท่าที่ทำได้ (แต่ถูกซ่อนในเอกสาร) อย่างไรก็ตาม ชื่อเหล่านี้จะถูกนำออกในอนาคต
ดังนั้นเราขอแนะนำให้ย้ายมาใช้ prelude หรือโครงสร้างโมดูลใหม่ใน import ของคุณ
