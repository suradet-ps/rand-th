# กระบวนการสุ่ม

คุณอาจสังเกตว่าเทรต [`Distribution`] ไม่อนุญาตให้แก้ไขตัวเอง (ไม่มีเมธอด `&mut self`) นี่เป็นเจตนาในการออกแบบ: การแจกแจงความน่าจะเป็นนิยามเป็นการแมปจากเหตุการณ์ไปยังความน่าจะเป็น

ในทางกลับกัน [กระบวนการสโทแคสติก (Stochastic Process)](https://en.wikipedia.org/wiki/Stochastic_process) ว่าด้วยกลุ่มของตัวแปร (หรือสถานะ) ที่เปลี่ยนแปลงในลักษณะสุ่ม

เราไม่ได้พยายามนิยาม API ทั่วไปที่ครอบคลุมกระบวนการสุ่ม หรือให้การรองรับการจำลองโดยตรง ในที่นี้เราเพียงพูดถึงบางส่วนเท่านั้น


## การสุ่มแบบไม่ใส่คืน

ยกตัวอย่างเช่น ถุงหนึ่งใบมีลูกแก้วสีแดง 10 ลูกและสีเขียว 30 ลูก ความน่าจะเป็นเริ่มต้นที่ลูกแก้วที่สุ่มจากถุงจะเป็นสีแดงคือ `10/(10 + 30) = ¼ = 0.25` หากลูกแรก*เป็น*สีแดงและ*ไม่ถูกใส่คืน* ความน่าจะเป็นที่ลูกที่สองที่สุ่มจากถุงจะเป็นสีแดงคือ `9/(9 + 30) = 3/13 ≅ 0.23`

เครต `rand` ไม่มีระบบใดรองรับการสุ่มแบบไม่ใส่คืนทีละขั้น สิ่งที่มันมีคือการรองรับการสุ่มค่าที่แตกต่างกันหลายค่าจากลำดับในขั้นตอนเดียว:
[`IteratorRandom::choose_multiple`] และ [`SliceRandom::choose_multiple`]

หากคุณต้องการ implement การสุ่มทีละขั้นด้วยตัวเอง นี่คือแนวคิดบางประการ:

-   ใส่สมาชิกทั้งหมดลงใน `Vec` แต่ละขั้นให้สุ่มและนำค่าหนึ่งออก โปรดทราบว่า
    หากเซตของสมาชิกที่เป็นไปได้ทั้งหมดมีขนาดใหญ่ วิธีนี้จะไม่มีประสิทธิภาพ
    เนื่องจาก `Vec::remove` เป็น `O(n)` และเนื่องจากต้องสร้างสมาชิกทั้งหมดขึ้นมา
-   ใส่สมาชิกทั้งหมดลงใน `Vec` แล้วสับ แต่ละขั้นเพียงนำสมาชิกตัวถัดไป
-   สร้างวิธีสุ่มค่าจากการแจกแจงเริ่มต้น บวกกับ `HashSet` ว่างที่แทนค่า
    "ถูกใช้ไปแล้ว" แต่ละขั้นให้สุ่มค่าหนึ่งค่า หากค่าอยู่ใน `HashSet` แล้ว
    ให้ปฏิเสธค่านั้นและสุ่มใหม่ มิฉะนั้นให้ใส่สำเนาลงใน `HashSet` แล้วคืนค่า
    โปรดทราบว่าวิธีนี้ไม่มีประสิทธิภาพเว้นแต่จำนวนตัวอย่างที่สุ่มจะน้อยกว่า
    จำนวนสมาชิกที่มีอยู่มาก
-   ศึกษา [`src/seq/index.rs`]: มีอัลกอริทึมการสุ่มหลายแบบที่ใช้อยู่
    ซึ่งอาจปรับใช้กับงานนี้ได้
