# การอัปเดต

คู่มือนี้จัดทำขึ้นเพื่อช่วยในการอัปเกรดไปยังเวอร์ชันไมเนอร์หรือเมเจอร์ถัดไปของ Rand
โปรดทราบว่าการอัปเดตไปยังเวอร์ชันแพตช์ถัดไป (เช่น 0.5.1 ไปเป็น 0.5.2)
ไม่ควรต้องแก้ไขโค้ดเลย

คู่มือนี้ให้รายละเอียดมากกว่า [บันทึกการเปลี่ยนแปลง] เล็กน้อย โดยเฉพาะคำแนะนำ
ในการใช้งานฟีเจอร์ใหม่ๆ และการย้ายออกจากฟีเจอร์เก่า

[บันทึกการเปลี่ยนแปลง]: https://github.com/rust-random/rand/blob/master/CHANGELOG.md
