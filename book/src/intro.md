# The Rust Rand Book (ฉบับภาษาไทย)

นี่คือเอกสารคู่มือฉบับสมบูรณ์สำหรับไลบรารีตัวสร้างเลขสุ่ม **Rand**om ในภาษา Rust

หนังสือเล่มนี้ประกอบด้วยเนื้อหาหลักดังนี้:

1.  [เริ่มต้นอย่างรวดเร็ว](quick-start.md)
1.  ภาพรวมของ[เครต ฟีเจอร์ และการรองรับแพลตฟอร์ม](crates.md)
3.  [คู่มือผู้ใช้](guide.md)
5.  [คู่มือการอัปเดต](update.md)
6.  [คู่มือผู้มีส่วนร่วม](contributing.md)
