# การอัปเดต

คู่มือนี้จัดทำขึ้นเพื่ออำนวยความสะดวกในการอัปเกรดไปยังเวอร์ชันไมเนอร์ (minor) หรือเมเจอร์ (major) ถัดไปของ Rand โปรดทราบว่าการอัปเดตไปยังเวอร์ชันแพตช์ (patch) ถัดไป (เช่น 0.5.1 ไปเป็น 0.5.2) จะต้องไม่จำเป็นต้องแก้ไขโค้ดใดๆ

คู่มือนี้ให้รายละเอียดเชิงลึกมากกว่า [บันทึกการเปลี่ยนแปลง] เล็กน้อย โดยเฉพาะอย่างยิ่งคำแนะนำในการใช้งานฟีเจอร์ใหม่ๆ ตลอดจนแนวทางการย้ายออกจากฟีเจอร์เก่าที่เลิกใช้แล้ว

[บันทึกการเปลี่ยนแปลง]: https://github.com/rust-random/rand/blob/master/CHANGELOG.md
